# 스토어 등록 이미지 (1280×800 PNG)

| 파일 | 헤드라인 | 화면 |
|---|---|---|
| `01-convert.png` | 자연어를 일정으로 | 입력 → 변환된 표 (반복 수업 + 회의 + 할 일) |
| `02-preflight.png` | 등록 전에 한 번 더 확인 | 시간 겹침·중복 경고, 2단계 등록 |
| `03-registered.png` | 잘못 등록해도 되돌리면 그만 | 등록 결과와 되돌리기 |
| `04-options.png` | 내 계정, 내 AI 키 | 설정 화면 |
| `05-colors.png` | 네이버에서 쓰던 색 그대로 | 35색 팔레트 + 카테고리 이름 |

- 왼쪽 캡션 + 오른쪽 실제 UI 레이아웃. UI는 확장에 들어가는 코드 그대로이고, 데이터만 샘플이다
  (개인 일정·계정이 노출되지 않도록).
- 다시 찍기: `node scripts/screenshots/serve.mjs` → 브라우저에서
  `http://127.0.0.1:8731/frame.html?src=/src/popup/popup.html&w=700&h=620&k=1.18&title=…&sub=…&bullets=A|B|C`
  `k` 값이 UI 확대 배율이다. 캡처 후 `sips` 로 1.6 비율 크롭 → 1280×800 축소.
